## 项目介绍

`Books-Management` 项目是一套图书馆信息管理系统，包括用户小程序以及后台管理系统，基于SpringBoot+MyBatis实现。前台商城系统包含用户注册登录、首页门户、图书查询、在线借阅、个人中心、我的信息、我的借阅、押金充值。后台管理系统包含统计分析、用户管理、分类管理、图书管理、借阅管理、管理员管理、统计报表、设置等模块。
